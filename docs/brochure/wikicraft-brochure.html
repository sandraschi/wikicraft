Product Requirements & Architecture Specification

1. Executive Summary

wikicraft is the central documentation, knowledge repository, and Architecture Decision Record (ADR) management system of the Back-Office Craft Suite.

2. Key Capabilities

  • Local Markdown Tree Ingestion: Automatically crawls local repositories and projects, extracting wiki links ([[link]]) and indexing documentation into SQLite FTS5.
  • Fast Full-Text Search (FTS5): Sub-millisecond snippet queries without cloud dependencies or telemetry leaks.
  • ADR Governance: Formally manages architectural decisions with status transitions (proposed, accepted, rejected, superseded) and broadcast notifications over the craft-biz bus.
  • Zero-Cloud Air-Gapped Operation: Eliminates external vendor subscription fees and preserves confidential system design data.

3. Replaces & Cost Savings

  • Replaces: Confluence (\$60/seat/mo), Notion Team (\$100/seat/mo), Slite (\$10/seat/mo).
  • Cost Reduction: 100% elimination of cloud subscription fees, zero latency, guaranteed uptime during network partitioning.

Complete MCP Tool & CLI Verb Reference

WikiCraft exposes 12 Model Context Protocol (MCP) tools over stdio JSON-RPC.

Tool Parameters Description
wiki_status none Reports database health, page counts, ADR counts, and link counts.
wiki_page_save id, title, content Saves or updates a markdown documentation page.
wiki_page_get id Retrieves a page by ID with backlinks and outgoing links.
wiki_page_list none Lists all documentation pages with version numbers and modification dates.
wiki_page_delete id Deletes a documentation page by ID.
wiki_page_search query Runs SQLite FTS5 full-text search and returns highlighted snippet matches.
wiki_page_backlinks id Discovers all pages that link to the specified page ID.
wiki_adr_save id, title, status, context, decision, consequences, superseded_by Creates or updates an ADR with status transitions.
wiki_adr_get id Fetches details and history of an Architecture Decision Record.
wiki_adr_list none Lists all Architecture Decision Records.
wiki_tree_import path Recursively indexes a folder of markdown files into the wiki.
wiki_inbox_drain none Acknowledges and clears pending signals in the wiki event bus inbox.
